# web-foundations-24330211014

* 1. Gemini
* ** URL: https://gemini.google.com
* ** Method:  GET
* ** Status Code: 200 OK
* ** Content-Type: text/html; charset=utf-8

* Request
* Request HTTP dalam konteks Gemini mengacu pada cara aplikasi atau sistem Anda mengirimkan data dan instruksi ke server API Gemini milik Google agar model kecerdasan buatan (AI) tersebut bisa memprosesnya dan memberikan jawaban.

* Response
* HTTP Response adalah pesan balasan yang dikirim oleh server Google kembali ke aplikasi Anda setelah Anda mengirimkan sebuah permintaan (HTTP Request).

* 2. Canva
* ** URL: https://www.canva.com/id_id/
* ** Method:  GET
* ** Status Code: 200 OK
* ** Content-Type: text/html;charset=utf-8

* Request
*  Pesan atau permintaan data yang dikirim oleh aplikasi luar (klien) ke server Canva melalui Canva Connect APIs menggunakan protokol HTTP agar sistem eksternal dapat berinteraksi dengan fitur Canva

* Response
* Data yang dikirim balik oleh server (baik server Canva atau server pihak ketiga) ke aplikasi Anda sebagai jawaban atas permintaan (request) yang dikirim sebelumnya.

* 3. Pinterest
* ** URL: https://id.pinterest.com/
* ** Method:  GET
* ** Status Code: 200 OK
* ** Content-Type: text/html; charset=utf-8

* Request
* Pesan atau permintaan elektronik yang dikirimkan oleh peramban (browser) atau aplikasi Pinterest di perangkat Anda ke server pusat Pinterest untuk meminta data atau melakukan aksi tertentu.

* Response
* HTTP response (respons HTTP) adalah data balasan yang dikirim oleh server Pinterest ke perangkat Anda (komputer atau ponsel) setelah perangkat Anda mengirimkan sebuah permintaan (HTTP request).
